Scope and demonstration

This page is a static preview of an existing software codebase. It is not a live interactive demonstration. The application UI calls Python FastAPI endpoints that cannot run on this Netlify static site.

For a functioning demonstration, run the repository's Python server locally or deploy it to a host that supports Python services. The README and demo walkthrough describe that process.

Starter product, not an operating SaaS business. User authentication, payments, and hosted production operation require additional implementation. Generated content and CMA estimates require human review. The current repository uses demonstration responses when no API key is configured. No revenue, customer base, or independent performance claim is made here.
